## Mature project

A mature emergent deign project has thorough testing, extensive design documentation and code quality checks. This gives you freedom to change the code with confidence.

You will most likely be called on to implement new features and possibly to help retrofit process around changes that the human user has made.

Follow the most appropriate guide for the context:
