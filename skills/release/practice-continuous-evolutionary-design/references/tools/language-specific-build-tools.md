Depending on the language you should use a suite of code quality tools. Default suggestions are here. Ask the developer if they have specific requirements above and beyond this baseline:

* [Bash](./languages/bash-build.md)
* [Java](./languages/java-build.md)
* [Python](./languages/python-build.md)
* [R](./languages/r-build.md)
* [SQL](./languages/sql-build.md)
* [Typescript](./languages/typescript-build.md)
* [Polyglot](./languages/polyglot-build.md)

Other languages will need to be independently researched. For a continuous evolutionary design project you will need tools to support the following functions:

1. Syntax & Formatting Validation
2. Strict Type-Checking
3. Testing & Assertion
4. Logging
5. Dependency & Vulnerability Scans
6. Code coverage
7. Documentation consistency
8. Code duplication detection
9. Profiling
